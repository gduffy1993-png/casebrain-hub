STRATEGY LEVERAGE NOTES
CCTV still
• This may assist the defence because the face is not clear and clothing alone is weak identification.
• This may assist the Crown because it places a similarly dressed person near the scene.
• It cannot safely prove identity without clearer source material or supporting evidence.
• Safe strategy move: chase full CCTV master and continuity before final ID advice.
• This point collapses if full footage clearly shows the defendant leaving or entering the scene.
Witness description
• This may assist the defence because the description is general and does not name a distinctive feature.
• This may assist the Crown because it broadly matches clothing in the CCTV still.
• It cannot safely exclude the defendant without the full statement and cross-checking the viewing conditions.
• Safe strategy move: test lighting, distance, duration and first description.
• This point collapses if the first account contains a distinctive matching feature.
No ID procedure recorded
• This may assist the defence because the file does not yet show a formal ID process.
• This may assist the Crown only if other recognition evidence exists.
• It cannot prove the identification is inadmissible at this stage.
• Safe strategy move: ask whether an ID procedure was considered or performed.
• This point collapses if a valid ID procedure note is served.
