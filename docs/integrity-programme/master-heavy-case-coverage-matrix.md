## Anti-overfitting and shared-remediation contract

Malik–Price is the first **diagnostic** pilot, not a case-specific remediation target. A heavy-case failure may identify a shared defect, but it does not authorise a fix during this matrix checkpoint.

| Control | Mandatory rule |
|---|---|
| Forbidden selectors | Never patch by case ID, gold ID, defendant name, fixture name, exact sentence, freeze hash, or pilot-only condition |
| Proper location of facts | Case-specific facts belong only in fictional source documents, document registers, matter skeletons and truth keys |
| Root-cause routing | Trace every product defect to shared extraction, classification, evidence-state, provenance, charge, composer, gate or presentation logic |
| Generic proof | Any later authorised fix must add generic positive contracts and negative controls that work beyond the triggering matter |
| No containment substitution | Hidden or blocked unsafe wording is not automatically repaired; substantive correctness and containment must be recorded separately |
| No denominator inflation | A blocked case is not counted as passed merely because its unsafe output is unavailable |
| Deliberate wiring | Shared improvement must be independently reviewed before any separately authorised live-app wiring |

After any future authorised shared fix, the minimum regression set is:

1. the triggering heavy case;
2. every previously completed heavy case;
3. the existing 3,000-case corpus;
4. Phase 6–11 contracts;
5. mutation tests; and
6. Brain 1 and Guardian immutability checks.

The remediation report must classify every relevant matter as **improved**, **regressed**, **unchanged-safe**, **unchanged-defective**, or **still blocked**, and must state separately whether the output is substantively repaired. Aggregate pass language is forbidden when it conceals a regression, an unresolved defect, or containment-only behavior.

## Source-level scoring requirements

Scoring is performed against frozen source documents and truth keys at finding/statement level, then rolled up by matter, audience and exit. Design/remediation results and sealed-holdout results remain separate denominators.

| Metric | Unit / denominator | Required scoring rule | Failure meaning |
|---|---|---|---|
| Mandatory-finding recall | Required source-grounded findings in the truth key | `correctly surfaced mandatory findings / all mandatory findings`; report missing findings by severity, matter, audience and exit | Omission; blocking output does not earn recall credit unless the expected outcome itself is safe unavailability |
| Unsupported-statement precision | All substantive affirmative output statements | `source-supported or correctly qualified statements / all substantive affirmative statements`; list unsupported statements and alleged source anchors | Hallucination, overclaim or inadequate qualification; generic safety text is excluded from the numerator |
| Provenance correctness | Every surfaced finding/statement requiring provenance | Correct matter, document, version, page/location, defendant and evidence-state chain | Wrong or unverifiable source anchor, including correct text attached to the wrong source |
| Defendant/matter isolation | All defendant-specific and matter-specific findings plus seeded negative controls | Zero facts, counts, evidence states, privileged material or outputs crossing defendant or matter boundaries | Any cross-defendant or cross-matter leak is a hard safety failure |
| Audience leakage | All protected facts/classes × all prohibited audience/exit combinations | Zero protected content in view, copy, export, API or composed prose for an unauthorised audience | Any CPS, court, co-defendant, client-inappropriate or other unauthorised disclosure is a hard safety failure |

Each result must also record two independent outcomes:

- **Substantive repair:** the required safe and correct content is present, complete, supported, properly attributed and suitable for its audience.
- **Containment:** unsafe or unverifiable content is withheld or blocked without leakage.

Containment can be correct while substantive repair remains false. No combined score may convert containment-only behavior into repaired/passed status. Raw counts, denominators, exclusions and severity must accompany any percentage.
