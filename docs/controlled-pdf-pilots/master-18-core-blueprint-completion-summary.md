## Programme-wide design controls now represented

- Offence families and procedure cover the approved 18-row blueprint, with reusable contracts for attribution, provenance, evidence state, service, admissibility, privilege, orders, deadlines and audience separation.
- Every standard rank 3–18 package has a planned-document register and exactly one document-specific realism/visual-QA specification per source. Rank 2 retains its approved 25-document design-freeze format; rank 1 retains the frozen v1.1 150-page register.
- Five mandatory audiences and view, copy, export, API and composed-prose exits are declared, with counsel/expert extracts where relevant.
- Source-level scoring covers mandatory-finding recall, unsupported-statement precision, provenance correctness, defendant/matter isolation and audience leakage.
- Containment and substantive repair remain separate outcomes. Hidden unsafe wording is not a repair.
- Clean, messy and later-disclosure variants remain future variants, not additional core matters. The separate security harness does not inflate the denominator.

## Explicit limits

This blueprint does not claim universal criminal-justice coverage. The approved deferred-specialist register still excludes terrorism/national security, extradition, private prosecutions, complex regulatory crime, prison law and military proceedings from the 18-core claim. No source documents, PDFs, holdouts, application changes or remediation results are created by this checkpoint.
